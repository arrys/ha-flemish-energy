# Flemish Energy for Home Assistant

![Flemish Energy wordmark](docs/_static/flemish-energy-wordmark.svg)

Connect a Mijn Fluvius meter directly in the setup wizard and pair its published readings with your ENGIE Belgium contract rate. The wizard verifies the sources and adds **Energy & Costs** to the Home Assistant sidebar.

Requires Home Assistant 2026.11 or later. See the [installation and troubleshooting guide](docs/index.md) and [release notes](docs/changelog.md).

Build the documentation with `python -m pip install -r docs/requirements.txt` and `python -m sphinx -W -b html docs public`.
